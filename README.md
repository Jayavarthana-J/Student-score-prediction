# Student Score Prediction Using Machine Learning

A 14-day AI & ML Internship project at **Codomax Digital Solutions**.  
The project predicts student exam scores based on study hours using Machine Learning.

## 📌 Project Workflow

Study Hours & Student Data
↓
Data Collection
↓
Data Cleaning
↓
Data Visualization
↓
Train-Test Split
↓
Linear Regression
↓
Model Training
↓
Score Prediction
↓
Model Evaluation
↓
Prediction Application
↓
GitHub Publication

## 🎯 Objectives

- Learn Python programming fundamentals
- Understand NumPy for numerical operations
- Learn Pandas for data handling
- Perform data cleaning and preprocessing
- Visualize relationships within the dataset
- Understand Machine Learning fundamentals
- Build a Linear Regression model
- Predict student scores
- Evaluate model performance using MAE, MSE and R²
- Develop a simple prediction application
