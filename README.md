# Student Score Prediction Using Machine Learning

A 14-day AI & Machine Learning Internship project completed at **Codomax Digital Solutions**.

This project predicts student exam scores based on the number of study hours using Python and Machine Learning.

## 📌 Project Description

The project demonstrates a complete Machine Learning workflow, starting from Python programming and data handling to model training, prediction, evaluation, and application development.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- Git
- GitHub

## 📊 Dataset

The dataset contains:

- **Hours** – Number of study hours
- **Scores** – Student score

The objective is to identify the relationship between study hours and student scores and predict scores for new study-hour values.

## 🤖 Machine Learning Model

The project uses Linear Regression to predict student scores based on study hours.

| Input | Output |
|---|---|
| Study Hours | Predicted Student Score |

## 📈 Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## 📦 Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project folder:

```bash
cd student-score-prediction
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## 🚀 How to Run

Run the prediction application:

```bash
python day11_prediction_app.py
```

Enter the number of study hours when prompted.

Example:

```
Enter the number of study hours: 7

Study Hours     : 7.0
Predicted Score : 70.6
```
