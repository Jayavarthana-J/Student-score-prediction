# Student Score Prediction System

An AI & ML internship project (Codomax Digital Solutions) that predicts 
student examination scores based on study hours using Machine Learning.

## 📌 Project Overview
This project is built as part of the **AI & ML Internship** at 
**Codomax Digital Solutions**. It walks through the full ML workflow:
data preprocessing, visualization, model training, prediction, and 
evaluation, using Python and industry-standard libraries.

## 🎯 Goal
Build a model that takes a student's **study hours** as input and 
predicts their expected **exam score** using Linear Regression.

## 🛠️ Tech Stack
- Python 3.14
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
